# Tescom Connect downloads

Installers for Tescom Connect, the Tescom UPS monitor. The app updates itself
from here; you only need these for a first install.

| System | Download |
| --- | --- |
| Mac with Apple silicon | [Tescom-Connect-macOS-AppleSilicon.dmg](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-macOS-AppleSilicon.dmg) |
| Mac with Intel | [Tescom-Connect-macOS-Intel.dmg](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-macOS-Intel.dmg) |
| Windows | [Tescom-Connect-Windows-x64-setup.exe](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Windows-x64-setup.exe) |
| Windows on ARM | [Tescom-Connect-Windows-ARM64-setup.exe](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Windows-ARM64-setup.exe) |
| Linux (Debian, Ubuntu) | [Tescom-Connect-Linux-x64.deb](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Linux-x64.deb) or [AppImage](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Linux-x64.AppImage) |
| Raspberry Pi 64-bit, Linux on ARM | [Tescom-Connect-Linux-ARM64.deb](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Linux-ARM64.deb) or [AppImage](https://github.com/tescomgr/connect-releases/releases/latest/download/Tescom-Connect-Linux-ARM64.AppImage) |

Every version, with what changed: [Releases](https://github.com/tescomgr/connect-releases/releases).

This repository holds releases only; there is no source code here.
